# Phase 3. Built-in gamepad

Objective: replace the ROCKNIX joypad stack with `miyoo-flip-gamepad` for the Flip's UART pad.

Disposition: Closed, 2026-09-25.

Accepted behavior: original sticks, buttons, MENU, and rumble were accepted.

Limitations: Switch 1 replacement sticks were a compatibility target and were not called validated. Application handoff was Phase 4.

Records: [docs/research/phase-03-joypad-driver.md](../research/phase-03-joypad-driver.md). The phase heading is in the [2026-11-17 roadmap snapshot](../archive/roadmap-2026-11-17.md#phase-3-built-in-gamepad).
